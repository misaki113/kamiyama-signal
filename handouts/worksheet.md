## ③ 前処理：移動平均（15 分）

`ecg_noisy.csv` を ①② と同じ手順で読んで描いてください。細かいギザギザ（ノイズ）が乗っています。

**移動平均**：各点を「その点を中心とした k 個の平均」に置き換えて、なめらかにする方法です。

### 問い

1. 下の「素直な実装」は、足し算を全部でおよそ何回しますか。n と k で表してください。O 記法では？
2. となり合う 2 つの窓（i 番目の窓と i+1 番目の窓）で、足している点はどのくらい重なっていますか。
3. 重なっている分を足し直さずに済ませる方法はありますか。
4. 窓の幅 k を 9、25、75 と広げると、波形はどう変わりますか。R ピークの高さは？

### ヒント

- k は奇数にします（中心の 1 点 + 左右に `h = k ÷ 2`（切り捨て）個ずつ）
- 端では窓がはみ出します。はみ出さない範囲だけで平均してください
- **累積和**：`c[i] = x[0] + x[1] + … + x[i-1]` を先に作っておくと、
  `lo` 番目から `hi` 番目までの合計は、**引き算 1 回**で出せます

### 擬似コード（素直な実装）

```
関数 移動平均_素直(x, k):
    n ← 長さ(x)
    h ← k ÷ 2 （切り捨て）
    y ← 長さ n の配列
    i を 0 から n-1 まで、くり返す:
        lo ← max(0, i - h)
        hi ← min(n - 1, i + h)
        合計 ← 0
        j を [ ケ ] から [ コ ] まで、くり返す:
            合計 ← 合計 + x[j]
        y[i] ← 合計 ÷ [ サ ]
    y を返す
```

### 擬似コード（累積和の実装）

```
関数 移動平均_累積和(x, k):
    n ← 長さ(x)
    h ← k ÷ 2 （切り捨て）
    c ← 長さ n+1 の配列（全部 0）
    i を 0 から n-1 まで、くり返す:
        c[i + 1] ← c[i] + [ シ ]
    y ← 長さ n の配列
    i を 0 から n-1 まで、くり返す:
        lo ← max(0, i - h)
        hi ← min(n - 1, i + h)
        y[i] ← ( [ ス ] - [ セ ] ) ÷ (hi - lo + 1)
    y を返す
```
