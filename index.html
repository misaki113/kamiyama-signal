Python の知識は要りません。数字と True / False を変えて、実行するだけです。

1今日のワーク

何もインストールせずに、ブラウザの中で Python を動かせます。データも入っています。最初の起動に 30 秒ほどかかります。

ピーク検出のノートブックを開く

セルをクリックして Shift + Enter で実行します。上から順に進めて、結果はプリントに書き込みます。

  1. しきい値を超えた点を拾う
  2. R 1 つにつき、ピークを 1 点だけ選ぶ
  3. ノイズのあるデータで試す
  4. 手ごわいデータ

うまく開けないときは、Google Colab でも開けます（Google アカウントが必要）： Colab で開く

ブラウザの中で書いたものは、そのブラウザにだけ保存されます。残したいときは、ファイル名を右クリックして Download してください。

2データ

1 のノートブックには、はじめから入っています。自分の PC で動かす人だけ、ここからダウンロードして、プログラムと同じフォルダに置いてください。

  • ecg_clean.csv 心電図。ノイズが少ない（500 Hz、30 秒）。ワーク 1・2 で使う
  • ecg_noisy.csv 心電図。細かいノイズと電源ノイズ（60 Hz）が乗っている。ワーク 3 で使う
  • ecg_hard.csv 心電図。全体がゆっくり揺れる、手ごわいデータ。ワーク 4 で使う
  • motion_reach.csv 手を伸ばす運動の手先の位置（100 Hz、2 秒）。今日のワークでは使いません（数値微分のデモ用）
