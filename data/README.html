データについて

このフォルダの CSV はすべて合成データです。 授業用にプログラム（tools/generate_data.py）で 計算して作った波形で、実際の人から計測したものではありません。個人の情報は含みません。 各ファイルの先頭にも # note: SYNTHETIC DATA ... と書いてあります。

ファイル

ファイル 中身 サンプリング周波数 長さ
ecg_clean.csv 心電図。ノイズが少ない 500 Hz 30 秒（15000 点）
ecg_noisy.csv 心電図。細かいノイズと電源ノイズ（60 Hz）が乗っている 500 Hz 30 秒
ecg_hard.csv 心電図。基線がゆっくり揺れ、T 波が大きく、期外収縮が 1 回ある 500 Hz 30 秒
motion_reach.csv 手を 200 mm 先へ伸ばす運動（到達運動）の手先の位置 100 Hz 2 秒（200 点）

心拍数はどの心電図も 60〜80 bpm の間でゆっくり変わり、平均は約 70 bpm です。

形式

計測器が出力する CSV を模しています。文字コードは ASCII、改行は LF、区切りはカンマです。

# device: BioAmp-Sim ECG-01            ← # で始まる行はメタデータ（キー: 値）
# note: SYNTHETIC DATA (...)
# condition: rest, low noise
# recorded_at: 2026-11-20T10:00:00+09:00   ← 値の中にも ":" がある
# subject: synthetic-01
# lead: II
# sampling_rate_hz: 500                ← サンプリング周波数はここから取り出す
# unit: mV
# n_samples: 15000
index,ecg_mV,event                     ← 列名
0,-0.0071,REC_START                    ← ここからデータ
1,0.0055,                              ← event はほとんどの行で空
2,-0.0042,
  • index: 何番目の点か（0 始まりの整数）。時刻の列はありません。時刻は index / サンプリング周波数 で作ります
  • ecg_mV: 心電図の電圧 [mV]（motion_reach.csv では x_mm, y_mm: 手先の位置 [mm]）
  • event: イベントマーカー（文字列）。REC_START, MARK_1, MARK_2, REC_STOP, GO など。何もない行は空

作り直すとき

cd materials/R8_Kamiyama
uv run --with numpy python3 tools/generate_data.py

乱数の種を固定してあるので、何度実行しても同じファイルになります。 合成時の R ピークの位置は solutions/rpeak_truth/ に書き出され、解答例の検証 （tools/run_solutions.py）で使います。

実データに差し替えるとき

data/raw/ は実際に計測した心電図の置き場所として空けてあります（今回は使っていません）。 実データを使う場合は、氏名・ID・計測場所など個人を特定できる情報をメタデータから除いたうえで、 上の形式に整えてください。
